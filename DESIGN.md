# BulkBuddy design system

BulkBuddy follows the uploaded interface references: porcelain-white surfaces under luminous sky-blue and lavender atmosphere, with translucent frosted glass, fine orbital lines, delicate borders, and ultra-soft dimensional shadows. Warm editorial food photography provides contrast.

- **Typography:** Manrope; oversized lightweight tabular numerals for energy, compact readable labels elsewhere.
- **Color roles:** sky and lavender for atmosphere and selection, orange for energy/fat, green for confirmation/protein, charcoal ink.
- **Depth:** backdrop blur only where surfaces overlap color or imagery; orbital calorie sphere is the signature 3D moment.
- **Motion:** transform/opacity-based orbital drift, value transitions, springy controls, and route entrances; all disabled by system or in-app reduced motion.
- **Shape:** large glass sheets and photo masks use 20–24px radii; functional controls stay smaller and familiar.
- **Native handoff:** replace web routing with Expo Router native stack/tabs, dialogs with native sheets, images with expo-image, CSS perspective with Reanimated transforms, backdrop-filter with platform blur, and localStorage with device storage.
